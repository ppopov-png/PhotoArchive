# Yandex Disk SAF Test

Минимальное Android-приложение на Kotlin и Jetpack Compose, проверяющее запись через Android Storage Access Framework. Приложение не использует Yandex OAuth, Yandex REST API, backend или логин внутри приложения. Оно работает только с Uri, который выдаёт системный picker.

## Локальная конфигурация Yandex OAuth

Для следующего этапа client ID уже задан в `app/build.gradle.kts`. Секрет можно передать локально одним из способов.

Вариант с `.env.local`:

```properties
YANDEX_CLIENT_ID=fa628cc1d7024e4eb8b4d64216e87acb
YANDEX_CLIENT_SECRET=ваш_client_secret
```

Файл `.env.local` уже добавлен в `.gitignore`.

Вариант через переменную окружения:

```powershell
$env:YANDEX_CLIENT_SECRET = "ваш_client_secret"
.\gradlew.bat assembleDebug
```

Или добавить его в локальный файл `local.properties`:

```properties
YANDEX_CLIENT_ID=fa628cc1d7024e4eb8b4d64216e87acb
YANDEX_CLIENT_SECRET=ваш_client_secret
```

Файл `local.properties` исключён из Git. Пример находится в `local.properties.example`.

Важно: при сборке Android-приложения значение попадает в APK и может быть извлечено. Поэтому client secret нельзя считать защищённым внутри мобильного APK; для production OAuth-обмена нужен backend или официальный mobile SDK-поток без хранения секрета в приложении.

## Сборка APK

Требуется Android Studio с Android SDK (compileSdk 35) и JDK, встроенным в Android Studio.

Из корня проекта выполните:

```powershell
gradlew.bat assembleDebug
```

Готовый APK будет здесь: `app/build/outputs/apk/debug/app-debug.apk`.

Если wrapper ещё не создан в вашей копии проекта, откройте проект в Android Studio и выберите **Build → Build APK(s)**. Для командной сборки можно использовать установленный Gradle 8.9 и затем сгенерировать wrapper.

## Установка на Samsung

1. На телефоне включите **Параметры разработчика → Отладка по USB**.
2. Подключите Samsung S21 или более новую модель и подтвердите доверие компьютеру.
3. Установите APK командой:

```powershell
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

Также APK можно скопировать на телефон и открыть его вручную, разрешив установку из неизвестного источника для используемого файлового менеджера.

## Запуск теста

1. Убедитесь, что официальное приложение Яндекс Диск установлено и пользователь в нём авторизован.
2. Запустите **Yandex Disk SAF Test**.
3. Нажмите **Выбрать папку**.
4. В системном Android folder picker найдите провайдер Яндекс Диска. Название и расположение могут отличаться по версии приложения; обычно он виден как **Яндекс Диск** среди доступных мест/хранилищ. Выберите папку внутри него и подтвердите кнопкой **Использовать эту папку**.
5. На главном экране должен появиться сохранённый `content://...` URI.
6. Нажмите **Проверить запись**.

## Успешный результат

Успех подтверждён, если приложение показывает **Запись успешна**, а в выбранной папке Яндекс Диска реально появляется:

```text
TEST_SAF/test.txt
```

Содержимое файла: `Storage Access Framework write test`.

Кнопка **Удалить тестовый файл** удаляет только `TEST_SAF/test.txt`; пользовательская папка и другие файлы не удаляются. Папка `TEST_SAF` не удаляется.

Если провайдер Яндекс Диска не появляется в picker или запись завершается ошибкой, это означает, что установленная версия приложения/провайдера не предоставляет нужный SAF-доступ. Полный текст ошибки виден на экране, а детали записываются в Logcat с тегом `SafTest`:

```powershell
adb logcat -s SafTest
```

Не переходите к переносу медиатеки, пока этот тест не завершится успешно.
